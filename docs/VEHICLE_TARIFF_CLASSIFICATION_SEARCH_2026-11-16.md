# Поиск классификатора автомобилей и исключение «Эконома»

Дата: 2026-11-16. Указание владельца: «Эконом нужно исключить, так как этот
тариф у нас исключен». На вопрос об источнике таблицы владелец поручил
поискать её по репозиторию. Правило принято без повторного утверждения.

## Найдено

В действующем коде поддерживаются только **Комфорт, Бизнес, Минивэн**:

- backend `src/core/pricing.js` — comfort/business/minivan;
- `src/core/driverRegistrationService.js` — те же vehicle classes;
- migration0005 — CHECK(class IN ('comfort','business','minivan'));
- Android `Registration.CLASSES` и `registration_class_choices` — те же три класса.

Тариф «Эконом» отсутствует. `tests/pricing.test.mjs` прямо проверяет отказ
для `econom`; другие найденные упоминания — отрицательные order/router tests.
Прямой запуск текущих функций подтвердил: getTariffs возвращает ровно три
класса, normalizeTariff возвращает null и calculatePrice отказывает для
econom/economy/ECONOMY/«Эконом». Это не проверка класса конкретной модели.

В справочнике140 марок перечислены только названия марок и варианты поиска.
Строк моделей, годов и соответствия конкретному тарифу там нет. Утверждение
этого справочного состава не является допуском всех автомобилей марки.

## Применение указания владельца

В справочнике и постоянном контексте проекта зафиксировано: **Эконом исключён**,
разрешённые тарифы — Комфорт/Бизнес/Минивэн. Справочный список марок нельзя
использовать как список всех разрешённых автомобилей. Для допуска важны
конкретная модель и утверждённые правила её отнесения к тарифу; одну марку
автоматически относить к классу нельзя.

Конкретные марки и модели произвольно не удалялись: исходной модельной таблицы
нет, а одна марка может включать разные автомобили. Утверждённые140 названий
сохранены как справочный состав. Применение списка в качестве тарифного
каталога заблокировано отсутствием утверждённых модельных правил.
Следующая необходимая детализация — отдельная таблица допуска моделей только
для Комфорт/Бизнес/Минивэн, с критериями года/комплектации, если они потребуются
владельцу. Такая таблица должна быть предложена и явно утверждена; чужой
классификатор или догадка разработчика не становятся правилами сервиса.
